# Contoso Multi-Region Lab – Brief Guide

## Overview
This lab is designed to help users understand Azure multi-region deployment using CloudLabs. Each participant gets an isolated environment to practice safely.

## Environment Setup
Each user is provided with 3 Resource Groups:

- **RG1 (Jump VM)**  
  Used to connect via browser (RDP). Acts as the working machine.

- **RG2 (Sandbox)**  
  Users can create and manage their own resources here.

- **RG3 (Pre-deployed Resources)**  
  Contains a Storage Account deployed using an ARM template.

## Access
- Users register via a CloudLabs link
- Click **Connect** to access the VM in browser
- No local setup required

## Configuration Summary
- Deployment Plan: 3 Resource Groups  
- Permissions: Contributor on RG2 & RG3  
- Max Users: 20  
- Duration: 2 weeks  
- Attempts: 1  
- VM Access: Browser-based (RDP over HTTP)

## Learning Outcomes
- Understand Resource Groups
- Explore Azure Storage
- Create resources in Azure
- Learn basic multi-region concepts

## Conclusion
This lab provides a hands-on environment to practice Azure resource management and multi-region deployment basics.
